# Ciberseguridad-seguridad-informatica
Foro de debate Ciberseguridad

Este repositorio contiene el desarrollo del tema Ciberseguridad, Seguridad Informática y Seguridad de la Información, abordando la importancia de proteger los datos, sistemas y recursos tecnológicos dentro de una organización. Se explican las principales diferencias entre estos conceptos, las amenazas más comunes y la importancia de aplicar medidas de seguridad que involucren no solamente al software, sino también al personal, equipos, redes y procesos.
